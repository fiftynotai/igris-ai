## 📐 **Image Specifications for Terminal Background:**

**Optimal Settings:**
- **Resolution:** 2560x1440 or 1920x1080 (matches common displays)
- **Format:** JPG or PNG (Warp supports .jpg, .jpeg, .JPEG)
- **Aspect Ratio:** 16:9 (widescreen)
- **Color Profile:** sRGB
- **Opacity in Warp:** 10-30% (we'll set this in the theme)

**Composition Tips:**
- Character positioned **right side** or **bottom right** (doesn't block text)
- Lots of **negative space** on left (where terminal output appears)
- **Dark background** (#0E0E0F) to maintain FDL aesthetic
- **Subtle** so it doesn't distract from code

## 💡 **Pro Tips:**

**For DALL-E 3 (ChatGPT):**
- Start with "I NEED to test how the tool works with extremely simple prompts. DO NOT add any detail, just use it AS-IS:" before the prompt
- This prevents ChatGPT from rewriting your prompt
- Generate 2-3 variations, pick the best

**For Midjourney:**
- Use `--niji 6` for anime style
- Use `--ar 16:9` for widescreen
- Use `--style expressive` for more dynamic poses
- Can upscale with `U1`, `U2`, etc. buttons

**For Stable Diffusion:**
- Use models trained on anime/Digimon art (e.g., "AnyLoRA", "Anything V5")
- Increase steps to 30-50 for quality
- CFG scale: 7-9
- Sampler: DPM++ 2M Karras or Euler A
