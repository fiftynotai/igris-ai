# design_system

The project's authoritative visual language: its design tokens, component
conventions, and layout rules. This is the doc `/promote` graduates a **UI** /
design-token / component standard into.

## Section skeleton

> The structure `/ground` authors from. Fill each section from the project's
> actual UI code and design assets.

## Design tokens
Colors, typography, spacing, radii, elevation — the named primitives the UI is
built from.

## Components
The component set, each component's variants and states, and the conventions for
composing them.

## Layout & spacing
Grid, breakpoints, spacing scale, and the layout conventions the UI follows.

## Conventions & decisions
Visual decisions the project stands by (a chosen UI kit, a theming approach, a
rejected style) — each with its why.
